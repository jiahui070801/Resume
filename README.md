# Resume Website

A responsive personal resume / portfolio website built with HTML, CSS and JavaScript. It can be hosted for free using GitHub Pages.

## Files
- `index.html` — website content
- `style.css` — layout, colors and responsive styling
- `script.js` — mobile navigation and current year

## Customize
1. Open `index.html`.
2. Replace `Your Name`, email, location, education, project descriptions and profile details.
3. Update the GitHub / LinkedIn links.
4. Remove any skill or project that does not apply to you.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `resume-website`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a short time. Your website address will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/resume-website/`

## Important
GitHub Pages hosts static websites. HTML, CSS and client-side JavaScript work, but PHP and server-side database code do not run on GitHub Pages.
